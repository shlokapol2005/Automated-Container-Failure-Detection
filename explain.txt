Open 4 terminal windows before you start. Label them T1, T2, T3, T4.

What to show: Open your GitHub repo in the browser.

What to say: "All our code is version-controlled on GitHub. Every push to main automatically triggers the CI/CD pipeline."

STEP 2 — Show Source Code

app/app.py
 in your editor or on GitHub.

What to say: "This is our Flask REST API. The /health endpoint reports HEALTHY or UNHEALTHY. The /simulate-failure endpoint lets us intentionally trigger a failure for this demo."

STEP 3 — Run Automated Tests
T1 — Run:

powershell
python -m pytest tests/ -v
What to show: All 20 tests passing green.

What to say: "We have 20 automated tests. These run automatically in GitHub Actions before any Docker image is built."

STEP 4 — Show GitHub Actions Pipeline
What to show: GitHub repo → Actions tab → click the latest workflow run → show the two jobs: Run Automated Tests ✅ and Build & Push Docker Image ✅

What to say: "The pipeline automatically ran tests, built the Docker image, and pushed it to Docker Hub — all triggered by a single git push."

STEP 5 — Show Docker Hub Image
What to show: Open hub.docker.com → your repo → show flask-devops-app:latest with the push timestamp.

What to say: "The CI/CD pipeline pushed our image to Docker Hub. This is our container registry."

STEP 6 — Start Docker Compose Deployment
T1 — Run:

powershell
docker compose up -d --build
Then:

powershell
docker ps
What to show: Container flask-devops-app listed as Up, status healthy.

What to say: "We deploy locally using Docker Compose. The container is now running."

STEP 7 — Show Application is HEALTHY
T1 — Run:

powershell
curl http://localhost:5000/
curl http://localhost:5000/health
Expected output from /health:

json
{
  "status": "HEALTHY",
  "uptime_seconds": 12.5,
  "message": "Application is running normally"
}
What to say: "The application is live and returning HEALTHY with HTTP 200."

STEP 8 — Start the Health Monitor
T2 — Load your Discord webhook and run:

powershell
$env:DISCORD_WEBHOOK_URL = "https://discord.com/api/webhooks/YOUR_ID/YOUR_TOKEN"
$env:CONTAINER_NAME = "flask-devops-app"
$env:CHECK_INTERVAL = "10"
python monitor/monitor.py
What to show: Monitor printing green ✅ HEALTHY lines every 10 seconds.

What to say: "The monitor polls /health every 10 seconds. If it detects two consecutive failures, it automatically restarts the container."

STEP 9 — 🔥 Trigger Failure (The Key Demo Moment)
T3 — Run:

powershell
curl -X POST http://localhost:5000/simulate-failure
Expected response:

json
{
  "message": "Failure simulation ACTIVATED",
  "info": "The /health endpoint will now return UNHEALTHY (HTTP 503)"
}
Immediately switch to T2 to watch the monitor.

What to say: "I've just triggered a simulated failure. The /health endpoint now returns HTTP 503 UNHEALTHY."

STEP 10 — Watch Automatic Recovery
T2 — Monitor output you'll see:

What to say: "The monitor detected two consecutive failures, automatically ran docker restart, waited for the container to come back up, confirmed health, and is now sending a Discord notification."

STEP 11 — Show Discord Notification
What to show: Open Discord channel — show the two embeds that arrived:

Notification	Color

What to say: "The Discord notification confirms the complete automated flow — failure detected, container restarted, service recovered."
